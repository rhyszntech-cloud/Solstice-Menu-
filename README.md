# Solstice

### A Gorilla Tag Mod Menu

Solstice is a clean, modern, and feature-rich mod menu for Gorilla Tag, designed with simplicity, customization, and performance in mind.

No unnecessary clutter. No complicated setup. Just Solstice.

---

## Overview

Solstice aims to deliver a streamlined modding experience with an intuitive interface, customizable features, and a focus on usability.

## Features

- Advanced customization options
- AI-powered voice assistant
- Clean and intuitive navigation
- Quality-of-life features
- Managed plugin support
- Lightweight, organized interface

## Installation

1. Install BepInEx 5.x.
2. Place `Solstice.dll` inside your `BepInEx/plugins` folder.
3. Launch Gorilla Tag.
4. Open the menu in-game using:
   - `Y` on VR
   - `Tab` or `H` on PC

## Requirements

- Gorilla Tag — SteamVR version (Rift is not supported)
- BepInEx 5.x
- Windows for Jarvis and voice controls
- A compatible operating system for the remaining features

## Solstice Plugins

Managed Solstice plugin DLLs can be placed in `<Gorilla Tag>/solstice/Plugins`.

Plugins are discovered after the menu finishes loading, including when Solstice is injected after the game has started.

Open **Settings > Plugins** to manage discovered plugins. Supported managed plugins can be enabled, disabled, or reloaded, and their mod buttons can be shown or hidden independently of their enabled state.

Legacy BepInEx Solstice plugins are listed as read-only.

Managed plugin DLLs may also retain a BepInEx entry point and be installed normally in `BepInEx/plugins`.
